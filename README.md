三国志 · 霸王的大陆（简化复刻版）
使用 Python + Pygame 制作的单机回合策略小游戏，参考FC经典游戏《三国志·霸王的大陆》，复刻核心玩法。
项目在字体处理上做了限制，全程不使用 "pygame.font.SysFont"，改用 "pygame.font.Font(字体路径,字号)" 的方式加载中文字体，避免乱码。

运行方式
安装 Python3.8 及以上版本，安装时勾选 "Add Python to PATH"
安装依赖:   bash pip install pygame
将 "sanguo.py"和 "config.json"放在同一个文件夹

命令行执行代码启动游戏:  python sanguo.py
若中文显示为方框，请把一款中文 ttf/ttc（如微软雅黑 msyh.ttc、黑体 simhei.ttf）放到游戏目录，代码会自动探测加载。

玩法介绍
开局选君主：曹操 / 刘备 / 孙权 三选一，其余两方由 AI 控制。
12 城网格地图：每座城池有兵力、粮草、驻守武将、潜伏在野武将。
回合制：每个城市指令消耗 1 回合；回合结束所有城池扣粮草，粮草为负则兵力衰减。
城市指令（在城市菜单按数字键）：
1 征兵：消耗粮草补充兵力
2 搜索：概率发现本城在野武将
3 调兵：调动兵力到相邻己方城池
4 进攻：出兵攻打相邻敌方 / 中立城池
攻城战 4 种战法：
1 交战：双方按武力差互扣兵力
2 斗将：双方出战武力最高武将单挑
3 火攻：依主将智力判定成功率，成功重创敌军
4 撤退：保留约七成兵力回城
胜利：占领全部 12 座城池。
失败：己方所有城池全部失守。

按键说明
标题：1 / 2 / 3 选择曹操 / 刘备 / 孙权 
大地图：← / → 在己方城池间移动光标 
大地图：回车 进入选中城池管理 
大地图：E 结束本回合（结算 + AI 行动）
菜单：1 ~ 9 / 0 按提示选择选项 
战斗：1 ~ 4 选择战法 
任意：Esc 返回上一级 
任意：Q 退出游戏文件结构

技术要点
字体加载：代码内置候选中文字体路径列表（Windows /macOS/ Linux），依次尝试，使用 pygame.font.Font (path, size) 加载，绝不调用 SysFont。
数据驱动：武将属性、城池坐标、归属、初始兵力粮草、潜伏武将全部外置在 config.json，改数值无需动代码。
AI：每个 AI 势力每回合自动征兵，并在兵力优势 ≥ 1.5 倍时主动进攻相邻弱小城池。
